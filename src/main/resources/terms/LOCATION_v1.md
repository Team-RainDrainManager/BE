# 위치정보 수집·이용 및 위치기반서비스 이용약관

빗물받이 집사는 「위치정보의 보호 및 이용 등에 관한 법률」에 따라 아래와 같이 개인위치정보를 이용합니다.

**제1조 (수집하는 위치정보와 시점)** 기기의 GPS 위치(위도·경도)를 **아래 기능을 쓸 때만** 수집합니다. 앱을 쓰지 않는 동안 위치를 계속 추적하지 않습니다.

| 기능 | 위치 이용 목적 | 보유 기간 |
| --- | --- | --- |
| 지도 보기 | 내 주변 빗물받이 표시 | 저장하지 않음 |
| 점검·청소·빗물받이 등록 사진 촬영 | 현장에서 찍은 사진인지 확인 (빗물받이와 50m 이상 떨어지면 검토) | 활동 기록과 함께 보관, 탈퇴 시 개인 식별 정보 삭제 |
| 제보 | 문제 위치 표시 | 제보 기록과 함께 보관 |
| 대신 점검 | 반경 300m 안의 요청인지 확인 | 마지막 위치 1건만 보관, 탈퇴 시 삭제 |

**제2조 (제3자 제공)** 개인위치정보를 다른 이용자나 제3자에게 제공하지 않습니다. 지도에는 빗물받이의 위치만 표시되며, 이용자의 위치는 표시되지 않습니다. 제보가 지자체로 전달될 때는 빗물받이 위치만 전달됩니다.

**제3조 (이용자 권리)**

1. 기기 설정에서 언제든 위치 권한을 끌 수 있습니다. 다만 점검·청소·대신 점검은 현장 확인이 필요해 이용할 수 없습니다.
2. 위치정보 이용·제공 사실 확인자료의 열람을 요구할 수 있습니다.
3. 동의를 철회하려면 탈퇴하거나 운영팀에 요청하세요.

**제4조 (만 14세 미만)** 만 14세 미만은 가입할 수 없으므로 해당 아동의 개인위치정보는 수집하지 않습니다.

**제5조 (위치정보관리책임자)** 성명: (기재) / 연락처: (운영팀 이메일 기재)

**제6조 (손해배상·분쟁)** 위치정보 처리로 손해를 입었다면 운영자에게 배상을 청구할 수 있으며, 방송통신위원회나 개인정보분쟁조정위원회에 분쟁 조정을 신청할 수 있습니다.

부칙: 서비스 개시일부터 시행합니다. (버전 1)
